# S181 週報 (07/02 - 07/15)

Type: Weekly

> 💡 本期（S181，07/02–07/15）以 OKR 相關的研究陪跑與元件設計系統推進為主軸。UED UX Lab 專案持續為 CUBE 歡迎大禮包研究提供陪跑支援，本期完成研究目標討論，聚焦「換機情境」下的驗證流程體驗，並敲定招募 6 位受訪者與四項驗證工具（登入兩步驟、裝置綁定、快速登入、生物辨識）的理解度評估設計；同時建立分析師合作窗口、撈取受訪名單並展開撈取條件討論。CUBE App 元件設計系統則完成共用元件 Story book 第二階段建置，發出多個共用元件的 PR。貸款首頁「預約諮詢」按鈕與 SSO 機制的功能開發與 Design QA 也在本期交付。此外，UED Research Library 前後端功能與部署已全數完成並實測通過，Work Hub 週報/月報架構（v1.24）也已同步更新回 routine prompt。

**核心成果與進度摘要**

### CUBE App 元件設計系統（Design System Components）

- 参與 7/6 元件雙週會 RD 討論、7/8 與 7/15 元件設計會議，持續與 RD 團隊對齊共用元件規範與開發協作事項。
- 完成共用元件 Story book 建立（第二階段），並發出 SegmentedControl、Tabs、PrimaryTab、Toast、Notification、Snackbar 等元件的 PR。

### UED UX Lab（研究陪跑與 CUBE 歡迎大禮包用戶研究）

- 7/2 出席 CUBE 歡迎大禮包研究會前會，為研究啟動預先對焦；7/9 召開研究目標討論會議，確認聚焦「換機情境」下的驗證流程體驗，釐清 Case 1（已啟用登入兩步驟）與 Case 2（未啟用）的流程邏輯差異，並評估用戶對登入兩步驟、裝置綁定、快速登入、生物辨識四項驗證工具的理解程度。
- 敲定招募 6 位受訪者（新舊戶比例仍在討論、傾向舊戶換機情境較多），規劃理想版與分析師可行版兩套招募條件；後續待完成標籤 mapping、與分析師確認可撈取欄位及會議時間等待辦事項。
- 撈取願意接受訪談的用戶名單（高優先度），作為研究招募的基礎資料；7/6 與商規分析師徐于婷建立合作窗口，7/15 接續召開撈取條件討論會議。

### 貸款首頁功能開發

- 為三個房貸方案的方案資訊頁新增「預約諮詢」按鈕，補齊按鈕點擊後導向的 web view 對應頁面，並彙整迭代前後的 Figma 設計稿；iOS、Android UI 與前後版設計稿彙整皆已完成。
- 針對此功能進行 Design QA，檢查項目涵蓋 iOS 畫面、Android 畫面（含文字放大 200%）、Fixed button UI 與注意事項 bottom sheet。
