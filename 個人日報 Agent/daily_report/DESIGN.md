# Daily Report Design

## Direction

Daily report output uses a project ledger style: compact, evidence-driven, and calm enough for end-of-day review. The report should feel like a durable work record, not a newsletter, dashboard, or presentation deck.

## Visual System

- Layout: single-column reading surface with a narrow evidence rail on desktop and inline evidence blocks on mobile.
- Color: light paper background, deep ink text, muted green for completed work, amber for blockers, blue for plans, and gray for evidence metadata.
- Typography: system sans-serif for all text. Use clear weight steps instead of decorative fonts.
- Components: section bands, workstream groups, evidence chips, and source metadata tables.
- Radius: 8px or less for report blocks and chips.

## Rules

- Every visual report keeps the same section order.
- Evidence IDs must be visible but secondary.
- Long text wraps naturally and never overlaps.
- HTML must be printable and readable without JavaScript.
- Do not use decorative gradients, floating cards, or oversized hero sections.
